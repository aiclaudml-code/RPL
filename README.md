# ⚽ Предиктивная Автообновляемая Модель Ставок РПЛ

Статистическая модель для прогнозирования ставок на Чемпионат России по футболу.

## Поддерживаемые рынки

| Рынок | Описание |
|-------|----------|
| 🟡 **Желтые карточки** | Тотал ЖК, командный тотал, линии 2.5/3.5/4.5/5.5 |
| ⛳ **Угловые** | Тотал угловых, линии 7.5/8.5/9.5/10.5/11.5 |
| 🚑 **Выход медбригады** | Кол-во замен из-за травм, линии 0.5/1.5/2.5/3.5 |
| 🎯 **Пенальти** | Да/Нет, вероятность назначения |

## Методология

### Модель предсказаний

1. **Желтые карточки** — распределение Пуассона с факторами:
   - Средние показатели команд (агрессивность)
   - Строгость судьи (индекс строгости)
   - Очные встречи (H2H)
   - Домашнее/гостевое преимущество

2. **Угловые** — распределение Пуассона с факторами:
   - Стиль игры (атакующий/оборонительный)
   - Качество атаки vs оборона соперника
   - Исторические данные матча

3. **Пенальти** — биномиальная модель:
   - Частота пенальти команд
   - Индекс пенальти судьи
   - H2H история

4. **Медбригада** — распределение Пуассона:
   - Физическая интенсивность игры
   - Количество нарушений
   - Строгость судьи

### Поиск ценных ставок (Value Betting)

```
Value = (P_модели × Коэффициент) - 1
Value > 5%  → Хорошая ставка
Value > 15% → Сильная ставка
```

### Управление банкроллом (Критерий Келли)

```
Kelly = (b×p - q) / b × fraction
где:
  b = коэффициент - 1
  p = вероятность победы (модель)
  q = вероятность проигрыша = 1 - p
  fraction = 0.25 (четверть Келли)
```

## Установка и запуск

```bash
# Установить зависимости
pip install -r requirements.txt

# Обновить данные и запустить демо
python main.py --update

# Анализ конкретного матча
python main.py --match "Зенит" "ЦСКА" "Казарцев С." --bankroll 10000 --bet 500

# Генерировать отчет по всем матчам
python main.py --report

# Запустить веб-дашборд (Streamlit)
python main.py --dashboard
# или напрямую:
streamlit run dashboard/app.py

# Автообновление каждые 30 минут
python main.py --auto-update
```

## Дашборд

Веб-интерфейс включает:

- **Анализ матчей** — выбор команд, судьи, прогноз по всем рынкам
- **Ценные ставки** — автоматическое выявление Value Bets
- **Калькулятор ставок** — расчет оптимального размера, ROI, симуляция Монте-Карло
- **Статистика команд** — сравнение команд по всем рынкам
- **Статистика судей** — строгость, индекс пенальти, влияние на рынки

## Важно

> ⚠️ Модель предназначена для исследовательских целей. Ставки несут финансовый риск.
> Используйте управление банкроллом и никогда не ставьте больше, чем готовы потерять.
